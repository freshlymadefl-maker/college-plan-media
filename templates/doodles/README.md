# Doodles (original, made for College Plan, free to use anywhere)
Hand-drawn-style accents in brand colors + two fun accents (orange #E8903A, coral #F05A28) and mist #C9D3D6.
Shapes: star, squiggle, burst, heart, plus, dots — each in gold, navy, orange, coral, mist, blue (e.g. star-gold.svg).
Use: `<img class="dd" src="../doodles/star-orange.svg" style="left:40px;top:330px;width:100px;transform:rotate(-12deg)">` with
`.dd{position:absolute;pointer-events:none;z-index:5}`. Rules: 2–5 per slide, only in empty space (never over text, faces or the stat card),
on photos keep them in corners/edges, mix 2–3 colors, slight random rotation. index.html shows all of them.
